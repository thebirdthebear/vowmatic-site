Privacy Policy

Last updated: July 23, 2026

The short version:

Your video and audio files never leave your computer. Vowmatic sends only small thumbnail images to AI for clip classification. These thumbnails are processed and discarded — never stored or used for AI training. The app also sends anonymous, metadata-only diagnostics about its own runs (never your footage) so we can tell when something stalls — see Section 4, and you can turn it off in Settings.

1. Who We Are

Vowmatic is operated by Canatella Productions, LLC, based in Cedar Park, Texas. We can be reached at [email protected].

2. What Vowmatic Processes

On Your Computer (never leaves your machine)

  • All video files (.MP4, .MOV, etc.)
  • All audio files (.WAV, .MP3, etc.)
  • Generated FCPXML timeline files
  • Whisper transcriptions (runs locally)
  • Audio cross-correlation sync (runs locally)
  • Rating calculations and cut decisions (runs locally)
  • All footage metadata and project files

Sent to AI Service (via our API proxy)

  • Frame thumbnails: Individual JPEG images extracted from your video footage, typically one frame every 30 seconds. These are small images (under 100KB each, approximately 1280 pixels wide) used for AI-powered clip classification ("is this ceremony or reception?") and quality assessment. Because they are frames from wedding footage, these thumbnails will often show recognizable people — the couple and their guests.
  • Text prompts: Classification instructions and scoring prompts sent alongside thumbnails. These contain no personal information.
  • Transcript text: For story assembly scoring, text transcriptions (generated locally by Whisper) may be sent to the AI service for emotional scoring. These contain spoken words from your wedding audio but no identifying metadata.

What is NOT sent

  • Full video files
  • Full audio files
  • Client names, venue names, or event details
  • Full file paths or file contents (paths are reduced to non-identifying metadata before anything is sent)
  • GPS data or location metadata

3. How Thumbnails Are Handled

Thumbnails are transmitted over encrypted HTTPS to our API proxy (hosted on Cloudflare Workers), which forwards them to Anthropic's Claude AI API for analysis. Per Anthropic's API data policy:

  • API inputs are not used to train AI models
  • Data is processed for the request and not retained long-term
  • Anthropic's full privacy policy is available at anthropic.com/privacy

Our API proxy does not store thumbnails. It logs only lightweight metadata: for AI requests, a timestamp, token identifier, model name, and token counts (for usage tracking and billing); and, for the product diagnostics described in Section 4, the metadata-only event fields listed there (such as the stage name and timing, the event type, the app and macOS version, the anonymous install ID, and the truncated token hash). No image data, footage, or file contents are ever logged. These logs are retained for 90 days for billing, reliability, and support purposes, then deleted.

4. Product Diagnostics

To keep Vowmatic reliable, the app sends a small stream of anonymous, metadata-only diagnostic events to our own server — a Cloudflare Worker operated by Canatella Productions, LLC. This is first-party (not a third party, and not the AI service); we use it to tell when someone's pipeline stalls or errors out so we can reach out and help. These events contain no footage and nothing that identifies you or your clients.

Each diagnostic event includes only:

  • Event type — one of a fixed set: app launch, app quit, or a pipeline stage starting, completing, sending a periodic heartbeat, or reporting an error
  • Pipeline stage name — which step is running (e.g. ingest, sync, analysis, autocut), drawn from a fixed internal list
  • Anonymous install ID — a random identifier generated on your machine and stored locally; it is never tied to your name or email
  • Truncated token hash — a shortened, one-way SHA-256 hash used only to group a single person's own installs; it cannot be reversed back to your API token
  • App version and macOS version (for example, "macOS 15.0")
  • Test-mode flag — whether the run was a test
  • Error code — a short code identifying the failure, included only when a stage errors

File paths are scrubbed to non-identifying metadata before any event is sent — never the couple's or venue's names. No video, audio, transcripts, thumbnails, file contents, or location data are included in diagnostics. These events are retained for 90 days and then deleted, alongside the request logs described in Section 3.

You can turn diagnostics off at any time from the app's Settings, using the diagnostics toggle. Turning it off stops these events; the app continues to work normally.

5. Your API Token

Your API token identifies your Vowmatic account for usage tracking and access control. It is stored locally in ~/.wedding_analyzer/config.json on your computer. We use it to:

  • Authenticate your API requests
  • Track usage for billing (subscription or per-wedding credits)
  • Enforce rate limits

6. Website Data Collection

Our website (vowmatic.ai) collects:

  • Email address — when you download Vowmatic or subscribe, to send your license key and updates
  • Google Analytics — anonymous page views and interactions to understand how people use our website
  • Meta Pixel — anonymous conversion tracking for our advertising
  • Stripe — payment information for subscriptions, processed entirely by Stripe (we never see your card number)

We do not sell personal information for money. If you are a California resident, our use of Google Analytics and Meta Pixel for advertising purposes may be considered a "share" of personal information under the CCPA/CPRA. You can exercise your opt-out rights as described in Section 7.

7. Your Rights

You can request access to, correction of, or deletion of any data we hold about you — including opting out of the advertising-related sharing described in Section 6 — by emailing [email protected]. Since Vowmatic processes footage locally, uninstalling the app removes all local processing data.

8. Changes

We may update this policy. Material changes will be communicated via email. The "last updated" date at the top always reflects the current version.
